# 소설 분석 백엔드 전체 검토 — 제품화까지의 격차 분석

> 전체 기능 검토 (2026-07-21). 현재 분석 백엔드가 **무엇을 갖췄고 무엇이
> 비었는지**를 제품 수준 소설 분석 도구(Fictionary·AutoCrit·ProWritingAid)와
> 계산 서사학 연구에 비추어 진단하고, MINT 헌법(온디바이스·결정적 우선·
> 백그라운드·증분·측정)에 맞는 구현 방향과 우선순위를 제시한다.

## 0. 한 줄 결론

MINT의 분석 백엔드는 **엔티티·지식·그래프 평면(누가·무엇을·언제)** 은 이미
동종 최고 수준으로 깊다. 그러나 **개발 편집(developmental editing) 평면
(이 장면이 왜 필요한가·이야기가 잘 굴러가는가·독자가 지루한가)** 은 거의
비어 있다. 제품화의 핵심은 신규 저장소가 아니라 **이미 있는 씬·사건·상태
인프라 위에 "편집자의 시선"을 얹는 것**이다 — 대부분 결정적 통계 또는 기존 LLM
패스 확장으로 가능하다.

## 1. 현재 갖춘 것 (정확한 재고)

| 대화 | `DialogueAttribution`(화자 귀속·존대)·`ConversationCapture` | ✅ 성숙 |

| 핵심 장면 | `KeyScene` — 작가 관리 sparse 장면 | ✅ 신규(M11) |

이 이야기가 좋은가"를 보는 줄은 사실상 없다.**

## 2. 제품 수준 기준선 — 조사 결과

경쟁 제품과 연구가 다루는 것을 MINT 커버리지와 대조한다.

- **Fictionary** — 스토리 레벨 개발 편집. 씬마다 **38개 스토리 요소**를
  Character/Plot/Setting 3범주로 평가(§2.1). MINT의 직접 비교 대상.
- **AutoCrit** — 산문+구조. **페이싱 리포트**(장면이 늘어지나/급한가), 대화·POV
  일관성, 캐릭터·갈등·세계관·타임라인·**모순** 리포트(챕터별+전체).
- **ProWritingAid** — 문법·문체·가독성·일관성 + 페이싱/구조/캐릭터 빅픽처.
- **계산 서사학** — Reagan et al.: 1,300권에서 **6가지 기본 감정 아크**(Rise·
  Fall·Fall-rise·Rise-fall·Rise-fall-rise·Fall-rise-fall). 감정 아크의 복잡도·
  일관성이 **문학적 품질·독자 선호와 상관**. 관계 아크(relational arcs)를 서사
  구조 단위로 보는 최신 연구.

### 2.1 Fictionary 38요소 대 MINT 커버리지

| 범주 | 요소(발췌) | MINT |
| --- | --- | --- |
| Character | POV, POV Goal(외/내), Character Arc, Goal↔Plot 연결, 실패 시 결과, **씬이 POV에 준 영향(±)**, 씬에서 얻은 앎, 등장 인물 | POV✅ 앎✅ / **목표·arc·씬 영향 ❌** |
| Plot | Scene Name, Story Arc(구성 단계), **Purpose(씬의 목적)**, 진입/퇴장 훅, **긴장(Tension)**, **갈등(Conflict)**, 폭로, 백스토리, 회상, 씬 클라이맥스 | 회상✅ 사건✅ / **목적·갈등·긴장·훅·구성단계 ❌** |
| Setting | **Location**, Date/Time, **Objects**, 오감(시청후미촉), 감정적 임팩트, 날씨 | location(문자열)⚠️ / **장소·사물 엔티티·오감·분위기 ❌** |

MINT는 38요소 중 **사실 계열 6~8개만** 만진다. 개발 편집의 뼈대(목적·갈등·
긴장·훅·목표·arc·세계관 엔티티)가 빠져 있다.

## 3. 격차 분석 — 우선순위별

각 격차는 **①제품 기준이 뭘 요구하나 ②MINT 현황 ③구현 방향(헌법 준수)
④결정성/토큰 비용 ⑤§5 체크리스트**로 정리한다.

### G1. 세계관 바이블 — 장소·사물·설정 엔티티 [최우선·구조적]

- **기준**: Fictionary Setting(11요소)·AutoCrit 세계관 리포트. 장편에서 세계
  규칙·장소·소품의 **일관성**이 인물만큼 중요하다("어제 파란 문이 오늘 빨갛다").
- **MINT 현황**: PLAN §6.2가 엔티티를 `인물|장소|사물|설정`으로 약속했으나
  **오직 Character만 구현**. `SceneMeta.location`은 씬당 자유 문자열일 뿐 장소
  엔티티·일관성 추적이 없다. 사물·세계 규칙은 전무.
- **방향**: `CharacterCard`를 일반 `StoryEntity`(type: 인물/장소/사물/설정)로
  일반화하고 감지 깔때기를 재사용. 장소는 **처격(에/에서) 우세 + 이동 동사 인접**,
  사물은 **목적격 우세 + 유정 신호 부재**라는 결정적 구조 신호로 후보를 잡는다
  (이미 `CharacterLexicon.Role`에 처격·목적격 있음 — 신호를 버리지 말고 활용).
  세계 규칙(설정 팩트)은 LLM 추출(SceneInsights 확장, "설정: …").
- **비용**: 감지 결정적, 팩트 추출만 LLM(기존 패스 확장). **증분·파생 캐시**.
- **§5**: 전부 예. 일관성 품질↑, 백그라운드, 씬 증분, 벤치 가능, 파생 캐시.

### G2. 씬 목적·갈등·긴장·훅 — 개발 편집 코어 [최우선]

- **기준**: Fictionary Plot의 심장(Purpose·Conflict·Tension·Entry/Exit Hook).
  "이 장면은 왜 존재하나? 갈등이 있나? 긴장이 오르나? 다음을 읽게 만드나?"
- **MINT 현황**: 씬 요약·사건은 있으나 **씬의 기능적 평가가 없다**. 목적 없는
  장면·갈등 없는 장면·훅 없는 장 마무리를 짚지 못한다.
- **방향**: `SceneInsights`를 확장한 **`SceneCraft`** 파생 — 씬당 1회 structured
  추출(목적 1문장·갈등 유무/종류·긴장 1~5·진입훅/퇴장훅 유무). KeyScene·챕터
  단위로 롤업해 "이 장은 목적이 겹친다/갈등이 없다"를 리포트. 확신 없으면 침묵
  (품질 > 적극성).
- **비용**: LLM(기존 씬 패스에 필드 추가 — 별도 호출로 형식 격리, §6.5 규율).
  긴장 수치는 결정적 폴백(§G3) 병행 가능.
- **§5**: 예. 단 "목적"은 작품 완결 후에야 확정되므로(Fictionary도 명시) **잠정**
  으로 표시하고 작가 오버라이드 허용.

### G3. 감정·긴장 아크 — 페이싱의 정량화 [고가치·결정적]

- **기준**: Reagan et al. 6 아크. 감정 궤적의 복잡도·일관성이 품질과 상관.
  AutoCrit 페이싱 리포트의 정량적 뼈대.
- **MINT 현황**: 감정 궤적을 **아무것도 추적하지 않는다**.
- **방향**: 씬(또는 슬라이딩 윈도)마다 **밸런스/긴장 점수**를 매겨 작품 곡선으로
  롤업. **1차는 결정적**: 한국어 감정 어휘 사전(긍/부정·공포·분노·기쁨) + 대화
  밀도 + 문장 길이 급변 + `StateDelta` 감정 필드. 곡선 형태를 6 아크로 분류.
  `NarrativeView`에 곡선 시각화(이미 타임라인/그래프 UI 있음).
- **비용**: **LLM 0토큰 가능**(어휘 사전). CLAUDE.md §2-5·§5-1에 이상적.
- **§5**: 전부 예. 페이싱 시각화는 예측 품질과 별개의 **작가 통찰 산출물**.

### G4. 산문 건강 리포트 — 반복·만연체·부사 남용 [고가치·결정적]

- **기준**: ProWritingAid/AutoCrit 산문 리포트. 반복어·부사 과다·필러·문장
  길이 단조·클리셰.
- **MINT 현황**: 인물 `speechProfile`은 있으나 **원고 전역 산문 건강 지표 없음**.
- **방향**: 결정적 스캐너 — ① 근접 반복어(같은 명사·동사 어간 N어절 내 재등장)
  ② 문장 길이 분포/단조도(만연체·단타 연속) ③ 부사·형용사 밀도 ④ 이중피동·
  번역투(닫힌 패턴 목록) ⑤ 종결어미 다양성. 전부 `hangulRuns`류 토크나이즈로
  가능. 비침습 배지·리포트(밑줄·팝업 금지, ConsistencyChecker 철학 계승).
- **비용**: LLM 0토큰. 사용자 확장 사전(불용어 파일 패턴 재사용).
- **§5**: 전부 예.

### G5. 연속성·모순 검사 확장 [고가치]

- **기준**: AutoCrit 모순 리포트(외모·타임라인·세계 규칙·소품 위치).
- **MINT 현황**: `ConsistencyChecker` **단 2종**(죽은 인물 발화·존대 붕괴).
- **방향**: 같은 결정적 프레임에 검사 추가 — ① **외모/사실 모순**(엔티티 팩트가
  씬 간 충돌: 눈 색·나이·철자, G1 엔티티 팩트 위에서) ② **타임라인 모순**(이미
  `ChronoOrder`가 사이클=Conflict 검출 — 이걸 경고로 승격) ③ **POV 헤드호핑**
  (NarrationMode가 3인칭 제한인데 다른 인물 내면 서술 — 이제 판정 가능) ④
  **세계 규칙 위반**(설정 팩트 대조). 전부 "확인해 보세요" 어조.
- **비용**: 대부분 결정적(기존 그래프·엔티티 재사용). ③은 NarrationMode 위에서.
- **§5**: 전부 예. `ChronoOrder` 충돌은 이미 계산됨 — 노출만 하면 된다.

### G6. 복선 회수 추적 — 설정→회수 [중가치]

- **기준**: 체호프의 총. "심었는데 회수 안 된 복선"·"근거 없이 튀어나온 반전".
- **MINT 현황**: `CausalLink.Kind.foreshadows`가 **있으나** 전용 설정→회수 짝짓기·
  미회수 감지가 없다. 플롯 스레드 상태(`open/resolved`)가 근사치일 뿐.
- **방향**: foreshadows 간선을 설정(앞)–회수(뒤) 짝으로 모아, 작품 끝까지 회수
  간선이 없는 설정을 **"미회수 복선?"** 후보로. 열린 `PlotThread`와 교차.
- **비용**: 결정적(기존 인과 간선 재사용) + 경계 케이스 LLM.
- **§5**: 예.

### G7. 인물 arc 종합 — 변화의 궤적 [중가치]

- **기준**: Fictionary Character Arc·Scene Impact. "이 인물이 시작과 끝에서
  달라졌나? 성장/몰락 곡선이 있나?"
- **MINT 현황**: `StateDelta` 스냅샷(점 상태)은 있으나 **arc 수준 종합이 없다**.
- **방향**: 인물별 StateDelta·앎·관계·감정을 시간축으로 접어 **변화 요약**
  (초기 상태 → 전환점 → 종착)을 파생. G3 감정 아크의 인물별 버전.
- **비용**: 결정적 조립 + 요약 LLM 1회/인물.
- **§5**: 예.

### G8. 대화 목소리 구별도 [중가치]

- **기준**: "화자 표시를 지워도 누가 말하는지 아는가"(인물 목소리 차별화).
- **MINT 현황**: 인물별 `speechProfile`이 **이미 있다** — 구별도 지표를 안 뽑을
  뿐. 저비용 확장 기회.
- **방향**: 인물 쌍의 말투 프로필 거리(종결어미·존대·문장 길이 분포)를 계산해
  "A와 B의 말투가 구별되지 않아요" 경고. 결정적.
- **§5**: 예. 기존 자산 재사용이라 ROI 높음.

### G9. 구성 단계 매핑 — 기승전결/3막 [중가치·조심]

- **기준**: Fictionary Story Arc. 발단·전개·위기·절정·결말 위치 추정.
- **MINT 현황**: 흐름·스레드는 있으나 **구성 단계 좌표가 없다**.
- **방향**: 감정/긴장 아크(G3) + 사건 중요도 + 갈등 밀도(G2)에서 **약한 신호로**
  절정 후보 등을 추정하되, **단정 금지**(작품마다 구조가 다르다 — 통념 주입은
  헌법 위반). 작가 확정 우선.
- **§5**: 예, 단 관대하게. 오판 위험이 커 후순위.

### G10. 독자 경험·명료성 [저~중가치]

- **기준**: 정보 과부하(인포덤프)·모호한 대명사 지시·인물 과다 등장 밀도.
- **MINT 현황**: 없음.
- **방향**: 결정적 휴리스틱 — 짧은 구간 신규 고유명사 밀도(등장 폭주), 서술
  대비 대화 비율 급락(설명 덩어리), 미해소 대명사. 비침습 힌트.
- **§5**: 예.

## 4. 횡단 인프라 격차

- **엔티티 일반화**: `CharacterCard` → `StoryEntity`(type 축). G1의 전제이자
  바이블 UI·Agent 도구의 공통 기반. 마이그레이션은 파생 캐시 재구축 + 사용자
  카드 type=인물 시드(스키마 무변경, `folderID` 옵셔널 패턴).
- **개발 편집 리포트 산출물**: 지금은 지식이 조각조각 UI에 흩어져 있다. 제품의
  **가치 표면**은 "이 원고의 개발 편집 리포트"(챕터별 목적·갈등·페이싱·모순·
  미회수 복선 요약) 한 장이다. Agent 도구로도 노출(`get_manuscript_report`).
- **장르 인지**: `JournalEntry.genre`가 이미 있다 — 장르별 기준(로맨스 비트·
  미스터리 단서 공정성)을 리포트 임계에 반영할 여지. 후순위.
- **감정/설정 어휘 사전**: G3·G4·G1의 공통 자산. `CharacterLexicon`처럼 컴파일
  기본값 + 사용자 파일 병합 패턴으로 확장 가능.

## 5. 권장 우선순위 (영향 × 헌법 적합 × 노력)

**즉효·결정적(LLM 0토큰, 낮은 리스크) 먼저 — 헌법 §2-5·§5-1의 정신.**

1. **G4 산문 건강** + **G3 감정/긴장 아크** — 결정적, 큰 통찰, 새 저장 없음.
   페이싱 시각화는 즉시 "제품처럼 보이는" 산출물.
2. **G5 연속성 확장**(특히 타임라인 모순 노출·헤드호핑) — 기존 `ChronoOrder`·
   `NarrationMode` 재사용, 거의 공짜.
3. **G8 목소리 구별도** — 기존 `speechProfile` 재사용, ROI 최고.
4. **G1 세계관 바이블**(엔티티 일반화) — 구조적으로 가장 크지만 장편 제품화의
   필수. 인물 인프라를 그대로 확장.
5. **G2 씬 목적·갈등·긴장** — 개발 편집 코어. 기존 씬 LLM 패스 확장.
6. **G7 인물 arc**, **G6 복선 회수**, **G10 명료성** — 위 자산 위에서 조립.
7. **G9 구성 단계** — 오판 위험, 신호 축적 후 관대하게.

**끝으로 — 하지 말 것(헌법 방어)**: 거대 컨텍스트에 원고 전체를 밀어 넣는
"전지적 비평"은 온디바이스·품질>적극성에 반한다. 각 격차는 **결정적으로 될
만큼 결정적으로**, LLM은 이해가 진짜 필요한 곳(씬 목적·세계 팩트·arc 요약)에만.
모든 산출은 파생 캐시이며 작가의 수정이 언제나 이긴다(§1-5).
