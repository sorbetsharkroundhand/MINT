# M6-6·8 대화 모드 + 존대 매트릭스 v1 · 바이블 패널 — 설계·구현 기록 (2026-07-17)

PLAN §6.4·§7·§10 구현. 앞 단계 기록: [m6-knowledge.md](m6-knowledge.md) ·
[m6-events.md](m6-events.md). m6-prep 6·8단계로 **M6 로드맵 항목이 전부 닫힌다.**

## 결정 1 — 귀속은 결정적 2단, LLM 판정은 v2로 보류

PLAN §7은 "모호하면 LLM 판정"을 열어 뒀지만 v1은 결정적 규칙만 쓴다:

1. **인접 서술**: 발화 문단의 서술부(대사를 걷어낸 나머지)에서 —
   발화 동사("말했·물었·대답했…" 어간 접두 매칭) 앞 가장 가까운 등록 이름,
   동사가 없으면 서술부의 **유일한** 등록 이름.
2. **교대 규칙**: 화자 **둘이 확정된** 대화 런에서만 미귀속 문단을 교대로 채운다.
   런 = 발화 문단의 연속(사이 서술 1문단 허용). 확정 화자 0·1·3+명이면 침묵.

보류 근거: LLM 귀속은 깊은 패스 예산·프롬프트·검증이 전부 새 설계 대상인데,
틀린 귀속은 **틀린 존대 신호**가 되어 대사를 통째로 망친다 (품질 > 적극성).
결정적 규칙의 재현율 한계(지문 없는 3인 대화 등)를 실측한 뒤에 연다 — PLAN §16.

## 결정 2 — 발화는 저장하지 않는다 (스냅샷 전용)

요약·사건과 달리 귀속은 LLM이 없어 **재계산이 공짜**다(문단 한 번 훑기, O(n)).
사이드카에 저장하면 무효화·스키마 관리만 생긴다 — 패스마다 원문에서 다시 만들어
`KnowledgeSnapshot.utterances`로만 발행한다. 스키마 버전도 그대로다 (v3).

## 결정 3 — 존대 판정은 닫힌 종결어미 규칙

존대: "요" 종결 + 격식체(-니다/-니까/-십시오/-시죠/-소서).
반말: 해체·해라체 꼬리 닫힌 목록. 문장별 판정 → 발화 단위 다수결, 갈리면 nil.

- **모호한 음절은 목록에 넣지 않는다**: "마" 단독은 "설마"를 반말로 오판했다
  (실측·수정) — 금지 명령은 "지 마"/"지마"로만 잡는다. "니"("어머니")·"네"("동네")
  류의 잔존 위험은 발화 다수결이 일부 흡수하고, 나머지는 v1 한계로 받는다.
- 판정 불가 = nil = 매트릭스에 기여하지 않음 — 틀린 신호보다 침묵 (CLAUDE.md §1-2).

## 결정 4 — 존대 매트릭스는 저장이 아니라 질의다

`honorific(from:to:before:)` — 커서 이전 발화만 fold해 (A→B) 방향의
존댓말/반말/혼재를 그때그때 계산한다. 시점 차단이 공짜로 성립한다:
5장에서 반말로 무너지는 관계라면, 3장을 고칠 때는 존댓말로 나온다.
청자는 **2인 런에서만** 부여 — 3인 이상의 방향 추정은 틀린 매트릭스를 만든다.

## 결정 5 — 대화 블록은 헤더 맨 뒤, 추정 불가면 통째로 침묵

커서가 열린 따옴표 안이면 (마지막 문단의 따옴표 짝 검사, 결정적):

```
지금 대화 중 — 다음 발화: 민준 (서연에게 존댓말) · 민준 말투 예: "괜찮습니다."
```

- 다음 화자 = 직전 발화의 청자 (없으면 직전 두 발화의 교대). 추정이 안 서면
  블록 자체를 만들지 않는다 — 틀린 화자 지목은 대사를 통째로 망친다.
- 위치는 A+B **뒤**(C 직전) — 이 블록은 커서 위치에 따라 변하므로 앞에 두면
  A+B의 KV 프리픽스까지 식힌다 (PLAN §12).
- 정지 사다리 확장 (PLAN §10): `CompletionParameters.stopAtUtteranceEnd`
  (요청별 런타임 값) — 대사 중간 마침표를 무시하고 닫는 따옴표(개행은 안전
  바닥)까지 간다. maxTokens는 그대로 — 상향은 측정 없는 튜닝이라 보류.

## 바이블 패널 (M6-8) — 팝오버 확장으로 마감

"패널 승격"(별도 사이드 패널)은 레이아웃 공사 대비 기능 이득이 없어 팝오버
확장으로 마감한다. M6 체크박스의 실체 기준:

- **열람**: 카드마다 자동 이해(상태 fold·최근 사건·말투 프로필)를 읽기 전용
  표시 — 예측 카드 줄과 **같은 질의**라 사용자가 보는 것 = 예측이 아는 것.
- **수정**: 카드 필드는 편집 가능. 파생 지식(요약·사건)의 직접 수정은 열지
  않는다 — 원문과 어긋난 채 다음 패스가 도로 덮는다 (원문이 유일한 진실 §2-1).
  파생 수정은 원문 또는 카드에서.
- **locked**: 소개를 직접 고치면 자동 잠금 + 행별 잠금 토글. 잠긴 카드는
  프로파일링이 채우지 않는다. 이전 저장 파일은 키 없음 = 잠기지 않음(옵셔널).
- **미확인 검토**: 후보 전부 나열 (기존: 맨 앞 하나) — 등록/무시.

## 검증

`DialogueAttributionTests` 19건: 존대 판정 4(존대·반말·판정불가·혼재) +
인접 서술 귀속 5(동사 인접·유일 이름·이름 둘·대사 내 이름 제외·미등록 차단) +
교대·청자 3 + 스냅샷 질의 4(비대칭 매트릭스·프로필·다음 화자·시점 차단) +
대화 모드 3(따옴표 감지·블록 조립·추정 불가 침묵).

⚠️ **미측정**: M6 완료 기준의 "존대 일치율 유의미 상승"은 리플레이 벤치에
존대 위반 검출(PLAN §13 ③)을 붙여야 잰다 — 벤치 확장은 M7 초입으로.
실기기 E2E(대화 중 제안이 닫는 따옴표에서 멈추는지)도 대기.

## v1 한계 (알고 받는 것)

- 같은 화자의 연속 발화 문단은 교대 규칙이 상대에게 잘못 배정할 수 있다.
- 지문 없는 3인 대화는 귀속되지 않는다 (LLM 판정 v2 대상).
- 작은따옴표(속마음)·겹낫표 없는 대사(웹소설 일부 관례)는 대사로 안 잡는다.
- 종결어미 규칙의 명사 오판 잔존 ("어머니" 등) — 다수결이 일부만 흡수.
