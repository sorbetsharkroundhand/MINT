# Incremental writing diagnostics scheduling

Task 9 adds an owned local-analysis controller, provider health outcomes, and separate byte-accounted caches/results. It does not install editor marks or presentation; those remain Tasks 10–12.

## Source and publication authority

A source snapshot alone cannot authorize native publication. The controller requires the post-binding `WritingEditorCommit` paired with the current runtime identity. Initial capture may prove revision zero; later source patches must advance the native revision. A verified metadata-only no-op commit may adopt a new runtime generation with the same native revision. The final bridge integration must forward only the existing capture's proved unchanged-source seam. The controller never compares whole manuscript bodies to guess whether a generation is metadata-only.

Document load may reset the prose index and capture one full source revision for existing intentional decisions. Ordinary edits apply complete bounded source pieces from Task 4, preserving unchanged piece identities. There is no per-key whole-body hash, copy, Markdown parse or projection reset. The controller invalidates intersecting input-context assessment as well as primary/related evidence, rebases unaffected ranges/anchors and retains their IDs. Occurrence IDs use document/rule/provider, persistent piece identity, piece-relative original position and an evidence digest; identical quotes remain distinct.

Every asynchronous boundary checks the private work epoch and the complete runtime/native/profile/provider/rule/window stamp. A/B/A, a metadata-generation change and an uncooperative old provider cannot publish into newer authority. Marked text, typing/Ghost, memory warning/critical, serious/critical thermal state and Low Power Mode close admission. Resuming waits for the normal 350ms pause. Production native cancellation still drains the already admitted bounded C call; this layer does not claim it interrupts that call.

## Coverage, health and memory

The generic engine retains compatibility with the provider protocol and snapshot initializer while exposing success/failed/unavailable outcomes without raw errors or manuscript excerpts. Invalid primary or related coordinates (negative, overflow, NSNotFound, outside input, or partial graphemes) are rejected. Range values preserve invalid coordinates for validation rather than silently clamping them onto unrelated prose. Korean-specific error classification remains at the provider boundary.

Only successfully assessed relative results enter the active-document LRU, keyed by exact window digest/text, language and profile/provider/rule revisions. Its default account is 16 MiB. A separate 16 MiB account covers active findings, bounded original evidence and assessed-window metadata. Exhaustion leaves partial/unassessed coverage rather than implying clean output. A document change drops the prior cache. Critical pressure drops reconstructible cache/results; manuscript and profile data remain intact.

Successful windows stop being dirty before the next await, so interruption preserves completed progress. Failed input contexts lose assessment, including overlap; failure never becomes an empty successful check. Unsupported source barriers remain explicit. Excluded code/media/math are not claimed as eligible prose. Explicit reports must retain the same distinction in Task 10.

Intentional suppression uses the source revision proved at load. After an ordinary source edit the revision is unverified; suppression stays quiet until explicit recapture/re-anchoring. Metadata-only authority adoption preserves a proved revision. Reading corrupt/future settings preserves the exact bytes and reports unavailable settings. A language without an installed provider is unavailable, not clean.

## Verification scope

Deterministic clocks and provider continuations cover the exact 349/350ms boundary, edit bursts, held old completions, A/B/A, metadata changes, composition/policy gates, cache promotion/eviction, byte-budget partial results, interrupted progress, failed-context invalidation, original formatted/emoji evidence, duplicate IDs, offset-preserving splices and owned intentional decisions. Synthetic 100k/300k edits assert bounded patch bytes/tree visits and no additional projection reset. Related editor/projection/style and real Korean provider suites remain part of verification.

No local MINT launch, actual paint/IME/accessibility acceptance or Store distribution proof is claimed. The controller and defaults remain internal; runtime lifetime/pressure composition, explicit reports, safe native edits and UI are separate delivery steps.
