# Korean sentence-flow and report validation

Task 8 composes conservative correctness, repetition and sentence-flow diagnostics in a private rule session for each exact request. Sentence-flow rules remain advisory: a verified causal ending immediately followed by a causal connector; four connected clauses in one sentence; the same first two lexical forms at adjacent sentence starts; a sentence over 120 UTF-16 units; or three adjacent sentences with the same clause count and ordered ending-family pattern. Length and rhythm patterns are informational. Ignored rules and dialogue-off do not disable correctness.

The pinned native analyzer can return `그래서` as either MAJ or overlapping `그렇/VA-I + 어서/EC`. The latter becomes one connector event only when the morphological pair and the exact original composed source both prove it. This avoids guessing from a suffix and avoids counting the connector as an extra clause. Directly quoted connector names remain quiet, including nested lexical mentions in dialogue.

## Bounded report ownership

Document requests use the existing lazy 4,096-unit splitter with at most 256 units of context overlap. Native calls retain the Task 6 limit of 1,024 units. Each analysis explicitly owns a contiguous, nonoverlapping, whole-grapheme range; midpoint ownership admits each source token/correctness finding once. Quote/paragraph, clause and sentence state continues across ownership boundaries. All returned ranges refer to the entire exact request, including original decomposed Hangul and emoji offsets. Incorrect ownership is rejected instead of published as clean coverage.

The provider awaits each chunk consumer before admitting the next window and checks cancellation before/after analysis and emission. Every request creates its own session and resets it on exit, including cancellation. The collecting `analyze` convenience may retain the final requested findings; the streaming pipeline retains bounded representative evidence and counters, rather than manuscript text or all historical occurrences. A completed run produces one pattern with representative original ranges, the last occurrence and its complete count.

A session retains at most 1,024 distinct candidate families per clause, the sensitivity threshold of representative occurrences per active family, two sentence-start forms as digests, three rhythm summaries, one incremental ending-pattern digest, and at most 32 quote delimiters. Family overflow marks style coverage partial. Quote-depth overflow marks the remaining request unsupported until reset, since guessing subsequent dialogue scope could publish false claims. Correctness remains independently assessed. Unsupported metadata is exposed by `analyzeChunks`; consumers must preserve it when displaying coverage. The collecting convenience throws on unsupported coverage because its generic findings-only protocol cannot represent partial assessment.
