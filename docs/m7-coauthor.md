# M7 "공저자" 1차 — 일관성 경고 · 수락률 로깅 · 인물 연대기 (2026-07-17)

PLAN §14 M7의 구현 기록. 원칙: 결정적으로 되는 것 먼저, 측정이 필요한 것은

## 일관성 경고 v1 (`ConsistencyChecker`) — 결정적, LLM 없음

예측 우선순위 1번 "일관성 유지"(CLAUDE.md §3)의 **열람 면**이다. 프롬프트가
막는 것(카드의 생사·존대쌍 주입)과 같은 지식으로, 이미 쓰인 원문도 검사한다.

**죽은 인물 발화**: 각 발화 위치에서 `stateAt(화자, before: 발화 위치)`의
생사 fold가 사망이면 경고. 시점 fold 덕에 "죽기 전 발화 정상 / 죽은 뒤만 경고"가
질의에서 공짜로 성립한다. 사망 판정은 닫힌 규칙(`사망` 포함·`죽음`·`죽었` 접두) —
"죽을 뻔했다"를 사망으로 오판하지 않게 보수적으로. 인물당 1회만 (반복은 소음).

**존대 붕괴**: (화자→청자) 쌍에서 같은 존대가 **3회 이상** 이어진 뒤 반대가
나오면 경고. 3회 미만은 우연일 수 있어 침묵 (품질 > 적극성). 쌍당 첫 전환
1회만 — 반말 트기(의도적 전환)면 그 뒤는 새 관계다.

**비침습**: 사이드바 ⑂ 탭의 점 + 타임라인 섹션 상단 목록만. 본문에 밑줄·팝업
금지. 어조는 단정이 아니라 "확인해 보세요" — 회상 장면·의도적 전환처럼 **작가가
옳은 경우가 항상 있다**. 경고는 스냅샷 발행 시 백그라운드에서 한 번 계산
(렌더 경로 재계산 금지 — editor-perf.md 4차 방법론).

**보류**: 설정 모순(세계관 위반) — 자유 서술 비교라 LLM 판정 필요, v1 범위 밖.

검증: `ConsistencyCheckerTests` 9건 (사망 전/후·중복 억제·확립 미달 침묵·
전환 후 재경고 없음·방향별 쌍·사망 판정 규칙).

## 실사용 수락률 로깅 (`AcceptanceMetrics`) — 로컬 전용

M6 측정의 결론("접두 일치 프록시는 지식 주입에 둔감")이 실사용 수락률을 품질의
**본 지표**로 승격시켰다. 문단 제안(§10)도 이 데이터로 게이트한다.

- `~/Documents/MINT/metrics.jsonl` — 한 줄 한 사건:
  `{"ts":…,"event":"shown|accepted_full|accepted_word|dismissed","mode":"fast|smart|story[-dialogue]","latencyMs":…}`
- 모드 축이 핵심 질문에 답한다: **story가 fast보다 수락률이 높은가?** —
  지식 주입의 가치를 실사용으로 판정 (M6 완료 기준 이관).
- 기록은 제안 단위(분당 몇 건) — 키 입력 경로 아님. IO는 전용 직렬 큐.
- Settings(⌘,) "품질 지표" 섹션에서 열람(노출·수락률·모드별)·삭제.
- **원격 전송 절대 금지** — 파일은 기기 밖으로 나가지 않는다 (CLAUDE.md §1-3).

## 인물 연대기 — 바이블 카드 펼침

카드마다 "연대기 · 사건 N" — 그 인물의 사건(+그 인물의 델타 변화)을 담화
순서로 편다. `eventIndexByCharacter` 역색인 + append-only StateDelta의 배당:
상태를 덮어썼다면 역사가 없어 이 UI도 없다 (PLAN §7 "공짜로 나온다").
스토리 그래프(관계망)는 후속 — 연대기가 데이터 검증을 겸한다.
