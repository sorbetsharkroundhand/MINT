# MINT 0.2.0 Writing Experience Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace MINT's feature-centric shell with a calm, content-centric writing experience while preserving the current editor strengths and exposing new intelligence through Living Margin, Ask MINT, Map, and Review.

**Architecture:** Keep `BlockTextView` and editor behavior intact while extracting `ContentView` orchestration into `Workspace/` views. `WorkspaceShellView` owns layout only; mode routing comes from the Project layer, and intelligence arrives as value models (`MarginInsight`, review models, retrieval results). Existing Narrative/Agent/Context implementations are mined for logic and semantics, not wholesale copied as primary surfaces.

**Tech Stack:** Swift 6, SwiftUI, AppKit/TextKit, existing MintTheme, XCTest, app bundle/UI smoke scripts

**Spec:** `docs/superpowers/specs/2026-09-02-mint-0.2.0-design.md`

## Global Constraints

- Preserve cursor-line highlight exactly as an editor invariant.
- Preserve Hangul IME composition safety and Ghost Tab/→/Esc behavior.
- Editor becomes a stable opaque editorial surface; selective material/glass is limited to chrome/context surfaces.
- No stacked glass and no dashboard-card proliferation.
- New shell is document/project centric, not Files/Bible/Narrative/Context/Agent centric.
- Living Margin and Review consume evidence through `EvidenceAnchor` values.
- AI surfaces must not steal editor focus or scroll position unless the user explicitly invokes/navigation-selects them.
- General Writing is a first-class path; Fiction-only controls remain hidden there.
- Replacement surface lands before legacy primary UI is removed.
