# MINT 0.2.0 Platform Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Introduce a general `WritingProject` domain, file-backed ProjectStore, non-destructive legacy migration, and mode-aware workspace routing without coupling the platform to Fiction.

**Architecture:** `WritingProject` is the in-memory aggregate. On disk, `project.json` stores only project/document metadata and relative paths; manuscript bodies live in `Documents/` or `Notes/`. `EntryStore` remains the legacy compatibility boundary. Workspace routing consumes only `WritingMode`.

**Tech Stack:** Swift 6, Foundation, SwiftUI, XCTest, Swift Package Manager

**Spec:** `docs/superpowers/specs/2026-09-02-mint-0.2.0-design.md`

## Global Constraints

- `WritingProject` is generic; Fiction is a mode, not the root type.
- General Writing does not depend on Fiction scene/character/timeline types.
- `DocumentOutline.Scene` is never a durable project/document identity.
- `entries.json` is read-only migration input and remains byte-identical.
- `project.json` does **not** duplicate manuscript bodies; it references document files.
- User-owned metadata/User Canon is durable; `Intelligence/` is rebuildable.
- Migration activates a project only after writing and re-reading all target files successfully.
- Existing editor body strings must survive adaptation/migration exactly.
- #100 must be green before product architecture PRs merge.

public struct ProjectDocumentRecord: Codable, Equatable, Sendable {
    public var id: WritingDocumentID
    public var title: String
    public var kind: WritingDocument.Kind
    public var relativePath: String
}

public struct ProjectManifest: Codable, Equatable, Sendable {
    public static let currentSchemaVersion = 1
    public var schemaVersion: Int
    public var id: WritingProjectID
    public var title: String
    public var mode: WritingMode
    public var documents: [ProjectDocumentRecord]
}

public protocol ProjectFileSystem: Sendable {
    func createDirectory(at url: URL) throws
    func writeAtomically(_ data: Data, to url: URL) throws
    func read(_ url: URL) throws -> Data
    func fileExists(at url: URL) -> Bool
}

public final class ProjectStore: @unchecked Sendable {
    public func save(_ project: WritingProject) throws
    public func load(id: WritingProjectID) throws -> WritingProject
    public func projectURL(id: WritingProjectID) -> URL
}
