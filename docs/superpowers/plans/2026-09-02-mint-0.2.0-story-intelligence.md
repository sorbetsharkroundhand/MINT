# MINT 0.2.0 Story Intelligence Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn MINT's existing Knowledge/Narrative system into an evidence-backed, incremental Fiction Intelligence stack that can remember long stories, retrieve relevant passages structurally, detect continuity candidates, and use an LLM only as a bounded judge when deterministic logic is insufficient.

**Architecture:** Preserve the current `KnowledgeSidecar`, `BackgroundIndexer`, `StoryEvent`, `StateDelta`, `NarrativeGraph`, and deterministic `ConsistencyChecker` behavior. Add explicit evidence anchors, temporal/atomic story knowledge, indexes and retrieval routing, then layer deterministic continuity and a cancellable Agent Judge on top. User Canon is stored outside derived knowledge and merged at query time. Ghost Completion consumes prepared memory snapshots only.

**Tech Stack:** Swift 6, Foundation, MLX through existing inference engine, XCTest, Swift Package Manager

**Spec:** `docs/superpowers/specs/2026-09-02-mint-0.2.0-design.md`

## Global Constraints

- Existing `SourceAnchor` is a utility namespace (`resilientQuery`, `jumpSnippet`, `searchSnippet`), not a persistent value type. New evidence values are named **`EvidenceAnchor`** and may use `SourceAnchor` utilities for re-anchoring.
- `DocumentOutline.Scene.contentHash` remains a derived cache anchor, not durable manuscript identity.
- Summary nodes route retrieval; they never become the sole evidence for a user-facing conflict.
- Unknown story time stays unknown and must not produce hard temporal conflicts.
- All user-visible important conflicts cite original manuscript evidence.
- Low-confidence or malformed Agent output produces silence, not a warning.
- Background analysis is cancellable and generation/project scoped; foreground completion has scheduling priority.
- User Canon is durable and lives outside `KnowledgeSidecar`.

## Story Intelligence Completion Gate

Before Map/Review are considered product-complete:

- [ ] Evidence values use `EvidenceAnchor`; existing `SourceAnchor` utility remains compatible.
- [ ] Hierarchical memory is project/document scoped and incrementally invalidated.
- [ ] Atomic story knowledge carries evidence, origin, and temporal information.
- [ ] Unknown story time never produces a hard temporal/location conflict by itself.
- [ ] Retrieval produces deterministic reasons and materialized original evidence.
- [ ] Existing dead-speaker/honorific tests still pass.
- [ ] Agent Judge cannot publish a conflict without bounded cited evidence and confidence gate.
- [ ] User Canon survives Intelligence deletion/rebuild and overrides automatic inference.
- [ ] Ghost Completion reads prepared memory only and remains free of disk/RAG work in the hot path.
- [ ] Full `swift test` and `swift build` pass.
