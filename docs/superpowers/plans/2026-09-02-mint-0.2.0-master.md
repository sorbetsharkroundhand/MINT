# MINT 0.2.0 Master Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver MINT 0.2.0 as a local AI writing platform with a first-class General Writing path and a deep Fiction Intelligence specialization.

**Architecture:** Build from a green CI baseline into a general `WritingProject` domain, non-destructive project storage, a content-centric workspace shell, and an incremental Story Intelligence stack. Keep foreground writing and Ghost Completion fast; all heavy understanding runs in cancellable background work and only surfaces evidence-backed results.

**Tech Stack:** Swift 6, SwiftUI, AppKit/TextKit, Swift Package Manager, MLX, XCTest, GitHub Actions, macOS 14+

**Spec:** `docs/superpowers/specs/2026-09-02-mint-0.2.0-design.md`

## Global Constraints

- Product identity is **Writing Platform, Fiction First**; do not make Fiction the top-level project type.
- Local-only: no remote inference and no telemetry.
- Preserve current Hangul IME behavior, Ghost Completion Tab/→/Esc semantics, and cursor-line highlight.
- User manuscript and User Canon are durable; AI-derived knowledge is rebuildable.
- `DocumentOutline.Scene` is derived analysis and must not become a persistent manuscript identity.
- Prediction hot paths perform no disk I/O and start no retrieval/LLM jobs.
- Foreground prediction preempts background indexing/judging.
- Important continuity warnings require original-text `SourceAnchor` evidence.
- Legacy `entries.json` is never modified in place by the 0.2.0 migration.
- UI uses a stable opaque editor surface with selective material/glass around it; no stacked transparency.
- Every implementation PR runs `swift test` and `swift build`; UI changes also run the app bundle/UI smoke relevant to the change.
