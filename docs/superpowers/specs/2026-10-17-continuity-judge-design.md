## Selected architecture
A pure immutable JudgeEvidencePacket and strict single-record decoder establish original authority before a request controller touches the ready local engine. Reuse the existing bounded ordered/draining instruction transport and ready-model backend, not continuation/Ghost cache or source-search query machinery. A scoped main-actor controller owns an explicit candidate request and publishes only fully verified decisions. Actual Review/Living Margin entry points/actions are #114/#270; no tool-opening auto-analysis or manuscript rewrite is added here.

Alternatives: free-form agent exploration violates the bounded contract; trusting JSON prose/citation paths permits invented evidence. Fetching or choosing a model violates the current owner-manual boundary. Use only a supplied candidate, captured current document, a bounded original excerpt and numbered verified quotes, with an already-ready expected model.

## Packet and output contracts
- Private packet factory consumes `ContinuityCandidate` and current `ProjectDocumentSnapshot`. Require Fiction manuscript, exact project/document scope and full source revision, valid origin and all literal originals at captured offsets. No re-anchoring to another revision or summary-only fallback. Retain no full manuscript body.
- Capture the complete source line containing the candidate's latest original as current excerpt (<=2048 UTF-16). Supply2...8 originals, each1...1024 UTF-16 and combined<=8192, as immutable1-based indexes. Oversize originals/excerpts refuse rather than truncate. Quotes remain byte-equivalent UTF-16; duplicate anchor identities refuse. A fresh UUID binds each request.
- Fixed system instructions distinguish candidate/quoted manuscript from instructions. JSON user data contains packet nonce, candidate kind/explanation and explicit numbered originals plus current excerpt; no tools, paths, model selection or unrestricted retrieval.
- Output is exactly one JSON object with keys `packet`, `verdict`, `confidence`, `explanation`, `citations`. Verdict is `conflict`, `intentionalPossible`, `insufficientEvidence` or `noConflict`; confidence finite0...1, explanation nonblank<=500 UTF-16, citations unique supplied1-based integers only. Root duplicate keys, including escaped spellings, extra fields, fences/prose/trailing records, malformed JSON, boolean confidence/indexes, control-only explanation, unknown nonce/indexes and response>4096 UTF-16 refuse.
- A visible conflict requires confidence>=0.8 and citation of every supplied candidate original, mapped back to the actual immutable EvidenceAnchor values. Other verdicts, low confidence and insufficient/malformed evidence stay quiet; no verdict creates writer canon/intentional state or edits. Explanation text grants no URL/source action.

## Execution and lifecycle
- Explicit request only, no model download/load or setup on open. Ready admission requires current selected stable model, enabled master/authorization, no management/pressure, no foreground Ghost and acceptable thermal/power policy. Supplemental ready instruction admission refuses an already active model operation; no model switch/wait is initiated by judging.
- Every request gets a ticket, runtime identity and packet nonce. A new request, edit/project/document transition, model/master/policy/foreground change cancels and retires old decisions before publishing new status. No automatic resume after policy recovery. Stream overflow/malformed data yields no partial verdict. Drain the actual producer/synchronizer before handoff; model reset ownership remains existing engine responsibility.
- Packet preparation runs off main; request controller uses only captured current document and existing project runtime. Snapshot generation/body ownership prevents A→B→A publication. No disk scan, retrieval, prediction-path LLM call or user-data mutation.
- Runtime support uses the same private CompletionController engine, existing foreground observer and authorization/model/memory/thermal/low-power signals. ProjectEditorRequests holds optional support for the later explicit Review/Margin action. This is a real ready-engine attachment, not a fake-only renderer. Opening tools starts no generation.
