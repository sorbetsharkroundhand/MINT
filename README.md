# MINT — Mac Intelligent Note Taker

**한글 글쓰기를 위한, 완전 온디바이스로 동작하는 스마트 자동완성 에디터.**

코드 에디터의 Copilot처럼 **다음에 쓸 말을 회색 글씨로 미리 보여주는** 자동완성을,
일상 저널링(일기 쓰기)에 가져온 macOS 앱입니다. 글을 쓰다 잠깐 멈추면 로컬 AI가
이어질 단어·구절을 제안하고, 마음에 들면 `Tab` 한 번으로 받아씁니다.

핵심은 **프라이버시**입니다. 모든 AI 추론이 여러분의 Mac 안(Apple MLX)에서만
일어나며, 일기 내용은 어떤 서버로도 전송되지 않습니다.

---

## 이 프로그램은 무엇인가

- **무엇**: 글을 쓰는 단일 창짜리 텍스트 에디터. 여기에 인라인 AI 자동완성이 붙어 있습니다.
- **누구를 위해**: 매일 한글로 일기·메모를 쓰면서, 내용이 밖으로 새는 것은 원치 않는 사람.
- **어떻게 다른가**: Notion 같은 툴의 AI 보조와 달리, 코드 에디터식 **빠른 인라인
  고스트 텍스트**를 글쓰기에 적용합니다. 그리고 클라우드가 아니라 **기기 안에서** 돌립니다.
- **지금 다루는 범위(MVP)**: 자동완성 엔진 + 단일 에디터 한 개. 노트 여러 개 관리·검색은
  아직 없습니다. 자세한 설계와 로드맵은 [PLAN.md](PLAN.md)에 있습니다.

## 어떻게 동작하는가 (사용자 경험)

1. 앱을 열면 빈 에디터가 뜨고, 하단 상태 바에 AI 모델 준비 상태가 표시됩니다
   (첫 실행은 모델을 내려받느라 시간이 걸립니다).
2. 한글로 글을 씁니다. 문장 끝에서 잠깐(약 0.35초) 멈추면, 커서 뒤에 이어질 내용이
   **회색 고스트 텍스트**로 나타납니다.
3. 제안이 마음에 들면 **`Tab`** — 본문에 삽입됩니다.
4. 마음에 안 들면 **`Esc`** 를 누르거나 그냥 계속 타이핑하면 제안이 사라집니다.
5. 한글을 조합하는 중(예: ㅎ→하→한)에는 제안이 뜨지 않습니다. 글자가 완성된 뒤에만 뜹니다.
6. 쓴 글은 자동 저장됩니다 → `~/Documents/MINT/journal.md` (일반 마크다운 파일).
   회색 제안은 `Tab`으로 받아쓰기 전까지 저장 파일에 들어가지 않습니다.

## 요구사항

- **Apple Silicon Mac** (M1 이상) — AI 추론이 Apple Silicon GPU 기반이라 필수입니다.
- **macOS 14+**, **Xcode 16+** (Swift 6)
- 첫 실행 시 AI 모델을 자동으로 내려받습니다.
  - 기본 모델은 용량이 큽니다(~20GB). 메모리가 부담되면 설정(⌘,)에서
    `mlx-community/Qwen2.5-3B-Instruct-4bit`(~1.9GB) 같은 가벼운 모델로 바꾸세요.

## 실행 방법

아직 배포용 `.app`은 없습니다. 소스에서 Xcode로 빌드해 실행합니다.

```bash
git clone <이 저장소 주소>
cd MINT
open Package.swift          # Xcode가 Swift 패키지로 엶
```

Xcode에서:
1. 상단에서 **MINT** 스킴을 선택하고 **⌘R** (실행).
2. 첫 빌드는 MLX 컴파일과 패키지 해석으로 수 분 걸립니다.
   중간에 **매크로 신뢰(Trust & Enable)** 확인이 뜨면 허용하세요.
3. 창이 뜨고 한글 타이핑이 되면 성공입니다.

설정은 앱 실행 후 **⌘,** — 사용할 모델, 프롬프트 방식, 자동완성이 뜨기까지의
대기 시간(디바운스), 제안 길이, 온도를 조절할 수 있습니다.

## 개발자용: 추론 성능 벤치 (MINTBench)

어떤 모델·프롬프트 방식이 한국어 품질과 속도에 가장 좋은지 측정하는 CLI 도구입니다.
앱을 띄우지 않고 터미널에서 로드 시간·첫 제안 지연·초당 토큰 수를 확인합니다.

```bash
swift run -c release MINTBench            # 기본 모델로 두 프롬프트 방식 비교
swift run -c release MINTBench --help     # 사용 가능한 옵션
```

측정 절차와 결과 기록표: [docs/m2-inference.md](docs/m2-inference.md)

## 프로젝트 진행 상태

| 단계 | 내용 | 상태 |
|------|------|------|
| M0 | 스캐폴드 (앱 셸 + MLX 의존성) | ✅ 완료 |
| M1 | 에디터 + 로컬 저장 | ✅ 완료 |
| M2 | 추론 선검증 (모델·프롬프트·지연 측정) | 🧪 코드 완료 — Mac 측정 대기 |
| M3 | 고스트 텍스트 자동완성 | 🔨 코드 완료 — Mac E2E 검증 대기 |
| M4 | 다듬기 (설정 UI·상태 바 등) | 🔨 부분 구현 |

> ⚠️ 개발은 Linux 환경에서 이뤄져 macOS 앱을 여기서 빌드·실행할 수 없습니다.
> 코드는 작성·커밋만 하고, **실제 빌드·실행·검증은 Apple Silicon Mac의 Xcode**에서 합니다.
> M2·M3의 상세 검증 절차는 [docs/m2-inference.md](docs/m2-inference.md),
> [docs/m3-ghost-text.md](docs/m3-ghost-text.md) 참고.
